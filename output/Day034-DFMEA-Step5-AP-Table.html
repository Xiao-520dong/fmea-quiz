🔄 温故知新：上期回顾

  • 上期核心1：废除传统 RPN（S×O×D）乘积法的原因在于其缺乏逻辑权重，无法体现 S（严重度）对人身安全和法规的决定性影响，易造成不同严重风险在数值上等同并诱发数字游戏。
  • 上期核心2：新版采用措施优先级（AP: High/Medium/Low）替代 RPN，其判定逻辑严格遵循 S → O → D 的逐级过滤机制，高优先级（H）必须识别适当措施或记录合理理由，低优先级（L）可由团队自行决定是否改进。

📖 今日核心知识

💡1. 核心概念与 AP 逻辑表深度拆解（原书 2.5.10）
新版手册提供的 AP（Action Priority）判定表不仅是 DFMEA 与 PFMEA 共用的逻辑矩阵，更是风险评估的标准标尺：
🔹
影响度极高/高（S = 9-10 / S = 7-8）：只要频度预测非常高（O = 8-10），无论探测度 D 是 1 还是 10，AP 级别一律无条件为 H（高优先级）；当 S = 7-8，O = 6-7 时，D 在 2-10 范围内均为 H，仅当 D = 1（非常高探测能力）时降为 M；当 S = 7-8 且 O = 1 时，无论 D 为何值，AP 均评定为 L。
🔹
影响度中等（S = 4-6）：当 O = 8-10 且 D = 5-10 时为 H，D = 1-4 时降为 M；当 O = 6-7 时，D = 2-10 均为 M，D = 1 降为 L；当 O = 2-3 时，全 D 范围均为 L。
🔹
影响度低（S = 2-3）：仅在频度极高（O = 8-10）且探测能力中等偏低（D = 5-10）时出现 M，其余绝大多数组合直接定级为 L。
🔹
影响度无（S = 1）：无论频度 O（1-10）和探测度 D（1-10）为何值，AP 恒定为 L。
🧭2. 步骤四至步骤五完整案例解析与供应链协作（原书 2.5.11 & 图 2.5-3）
• 原书车窗升降电机案例拆解：
🔸
失效影响（FE）：车窗升降电机的扭矩和转动速度过低（S = 6，中等影响）。
🔸
失效模式（FM）：换向系统的角度偏差导致间歇性错误连接线圈。
🔸
失效起因（FC）：电刷盒的碳刷接触部位弯曲。
🔸
当前预防控制（PC）：根据 FEM 6370 进行的电刷盒动态受力模拟（评定 O = 2）。
🔸
当前探测控制（DC）：抽样测试：依据测试规范 MRJ82/60 测量电刷盒的弹性和塑性变形影响（评定 D = 2）。
🔸
AP 判定：查表 S = 6，O = 2，D = 2 → 对应的措施优先级为 L（低）。
🔹
跨层级/跨组织技术风险协作（S 的传递）：风险分析的结果是客户与供应商达成一致的技术风险理解。OEM 将整车级 DFMEA 的功能、影响和 S 传递给一级供应商；一级供应商传达给二级供应商并输出产品特殊特性（SC/CC），作为下级 PFMEA 建立预防与探测控制的输入。
📱3. 传音研发/制造实战场景：手机中框按键与摄像头模组 AP 评定
• 传音影像模组 DFMEA 实操案例：
🔸
FE：非洲户外高湿强光环境下主摄防抖失效，画面模糊无法对焦（严重度 S = 7，主要功能丧失/顾客严重不满意）。
🔸
FM：OIS 悬丝阻尼胶老化脱落。
🔸
FC：胶水在 45℃ 极热及高紫外工况下粘接内聚力不足。
🔸
PC：参考同平台既有选胶设计规范（团队评定 O = 4，中等）。
🔸
DC：整机常规信赖度温湿度循环 240h 测试（未针对极端紫外加速老化，评定 D = 6，中等探测能力）。
🔸
AP 查表判定：在 S = 7-8 区间，O = 4-5 时，D = 5-6 对应的 AP 等级为 M（中优先级）。传音研发团队必须评审该 M 项，权衡是否将信赖度测试升级为双 85 + UV 联合强化测试以将 D 降至 3 以下。
🔹
设计到制造的传递：传音研发将按键侧键配合间隙的公差界限（S = 6）作为特殊特性输出给东莞/重庆制造基地，产线据此在 PFMEA 中配置高精度的自动化视觉检测治具（提升 D 级）并防呆卡合（提升 P 级）。
🚨4. 常见误区与避坑指南（衔接步骤六优化）
• 误区一：混淆“已计划的验证控制”与“步骤六优化措施”。原书 2.5.12 节明确强调：步骤六的措施不用于已经计划好的常规实验或测试，因为它们已经在 PC/DC 中记录并参与了初始 AP 评级；优化措施必须是额外的、针对降低 O 或提升 D 专门制定的新设计变更或新验证规范。
🔹
误区二：认为 AP 查表结果等于执行裁决。AP 仅仅是“优先排序”，高（H）代表优先最高，但绝不免除团队对部分关键 M 甚至特定 L 项的专业评审义务。
🔹
误区三：单向闭门评审，不与供应商同步 S 级。若主机厂不将系统级 FE 与 S 值向下传递，模组供应商（如镜头、马达厂商）在部件 DFMEA 中盲目将 S 评估为 3 或 4，会导致整个供应链对质量风险的严重低估。

第 3 题单选
传音手机研发团队在进行某机型侧键 DFMEA 风险分析时，识别出“按键卡滞”，严重度评估为 S = 6（中等影响）。若当前预防控制使起因发生概率处于 O = 4（中等），若希望该失效起因的措施优先级（AP）评定为 L（低），当前探测控制（D）必须至少达到什么水平？
解析：查原书第 69 页 AP 判定表：在 S = 4-6、O = 4-5 行中，当探测能力 D = 7-10 时 AP = M；当 D = 5-6 时 AP = L；当 D = 2-4 时 AP = L；当 D = 1 时 AP = L。因此，当 D 在 1 到 6 的范围内时，AP 均为 L。
