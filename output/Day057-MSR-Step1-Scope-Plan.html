Day 057：FMEA-MSR 步骤一（规划和准备）：项目边界、机电系统架构与计划

AIAG & VDA FMEA 手册百日精讲

🔄 温故知新：上期回顾

  • 上期核心1：FMEA-MSR（监视及系统响应补充FMEA）专用于分析电气/电子/可编程电子系统在客户运行期间的故障诊断、监视及故障安全响应能力，不能脱离DFMEA独立存在，而是对DFMEA中涉及安全与法规风险的机制深化。
  • 上期核心2：与传统DFMEA依赖设计预防/探测控制（消除起因或出厂拦截）不同，FMEA-MSR通过在线实时监控（Sensors/SW）与系统响应（如安全降级、跛行、切断危险源），在失效起因发生时阻断危险升级，从而有效降低严重度（S）对客户安全的潜在危害。

📖 今日核心知识

1. 核心概念与系统架构（Sensor - ECU - Actuator）
根据《AIAG & VDA FMEA 手册》第 4.1.2 节，FMEA-MSR 的第一步是“规划和准备”，其核心使命是明确评估对象，界定分析的“包含”与“排除”边界。
可纳入 FMEA-MSR 范围的典型对象为机械电子系统（Mechatronic Systems），该系统通常由至少以下三部分或其子集构成：
  • 传感器（Sensor）：负责采集物理量（如温度、电流、霍尔磁场、角位移等），并将模拟或数字信号传递给控制单元。
  • 电子控制单元（ECU / Logic Processing Unit）：内置微控制器（MCU/SOC/PMIC）与嵌入式软件算法，负责对传感器信号进行合理性校验、故障诊断判定并输出控制决策。
  • 执行器（Actuator）：根据控制指令动作，执行系统功能或安全响应（如 MOSFET 开关切断、马达反转、阻抗切换、显示告警等）。
系统间通过数据总线、电压、电流等电气物理量相互耦合，构成完整的闭环监控响应架构。
2. 边界确定的三大黄金准则与输入标准
原书明确指出，完成系统 DFMEA 后，需通过以下三大基本提问来严格界定是否启动 FMEA-MSR：
  1. 法规与伤害关联性：在电气/电子/可编程电子系统上完成 DFMEA 后，是否存在可能导致人员伤害（人身安全）或法规不符合的影响？（若无严重安全/法规影响，通常无需展开 MSR）。
  2. 故障可探测性：DFMEA 是否表明，导致伤害或不合规的故障起因，能够通过直接感知（硬件传感器）和/或合理性算法（软件逻辑）被系统在运行时探测到？
  3. 预期系统响应定义：DFMEA 是否表明，系统对探测到的起因具备明确的预期响应机制？例如：切换到降级运行状态（包括限制功率、进入安全模式或禁用设备）、主动通知用户/驾驶员，以及将诊断故障代码（DTC/Log）写入服务存储区。
此外，FMEA-MSR 的范围确定标准应参考：系统安全关联性、ISO 标准（如 ISO 26262 功能安全目标）、法律法规文件要求（如 UN/ECE 法规、FMVSS、OBD 车载诊断合规性等）。
3. 传音研发/制造实战场景（百瓦大功率快充监控系统）
在传音中高端机型的 120W/180W 极速快充系统研发中，系统架构与 MSR 边界定义完全贴合该闭环：
  • 传感器（Sensor）：主板电荷泵芯片内置的温度感测单元（Internal NTC）、电池包外置测温 NTC、电流采样电阻（Current Shunt）。
  • 控制逻辑（ECU）：充电管理芯片（Charger IC）与 AP 侧充电守护算法（Thermal Daemon），实时对采样电压、电流与温度做互检校验与越限合理性判断。
  • 执行器（Actuator）：快充回路的主隔离开关（Power MOSFET）与屏幕 UI 弹窗提示模块。
  • 三大准则落地：①若电荷泵短路过温，将直接导致电池热失控起火（威胁用户人身安全）；②该短路起因可通过 NTC 温度突变梯度结合 I2C 采样电流超标算法被直接探测；③探测到异常后，算法在 50ms 内切断快充 MOSFET、降低充电功率至 5W 慢充或彻底停充，在屏幕弹出“检测到充电接口过热，已暂停充电”提示，并将 Fault Code 存入 NVRAM/AP Panic 日志中供售后分析。因此，该快充热保护链路是传音硬件工程中开展 FMEA-MSR 的绝佳标准对象。
4. 常见误区与避坑指南
  • 误区一：把纯机械结构直接拉入 FMEA-MSR。
    纠偏：如果机械结构失效不包含传感器感知与逻辑芯片控制闭环（例如手机后盖跌落破裂），只能由传统 DFMEA 处理，不符合 MSR 的机电架构范畴。
  • 误区二：认为所有软件 Bug 都需要在 MSR 中穷举分析。
    纠偏：FMEA-MSR 重点评估的是硬件故障在运行时的监视与安全响应机制（HW 故障发生时，SW 算法如何安全保护）。纯软件功能逻辑缺陷应在软件工程、软件质量流程或专用 SW-FMEA 中管控。
  • 误区三：项目计划与产品主计划脱节（违背 5T 原则）。
    纠偏：手册 4.1.3 节强调使用 5T 方法（目的 Intent、时间 Timing、团队 Team、任务 Tasks、工具 Tools）。MSR 活动必须提早启动，且七步法各里程碑必须纳入传音产品开发流程（PDX/IPD）的软硬件架构锁定节点（如 EVT 评审前），不可在售后出问题后才被动“补材料”。

📚 内容来源：《AIAG & VDA FMEA 手册》第四章 4.1.2 - 4.1.3 节（PDF 第 123-124 页）
