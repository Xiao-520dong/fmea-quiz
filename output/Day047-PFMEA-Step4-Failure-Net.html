AIAG & VDA FMEA 手册百日精讲

🔄 温故知新：上期回顾

  • 上期核心2（FC描述禁止模糊化）：严禁用“缺陷”、“破损”、“操作失败”、“不遵守要求”或“不正常”等笼统词汇描述失效起因或模式，必须清晰阐明具体失效物理机制，才能为后续控制措施提供靶向目标。

📖 今日核心知识

1. 核心概念与失效网逻辑（Failure Net / Chain）
根据《AIAG & VDA FMEA 手册》3.4.7节，失效分析必须紧紧依托步骤三（功能分析）构建的层级逻辑导出故障链，即失效结构树/失效网（Failure Net）。
  • 关注要素的相对性：在三层结构中，关注要素被称为失效模式（FM），上一较高级别要素对应失效影响（FE），下一级工作要素对应失效起因（FC）。一个失效现象的角色完全取决于分析的视点。
  • 逻辑关联构建的核心提问法：
    • 构建 FM 与 FC 的关联：通过解答“为什么会出现失效模式？”（Why did the failure mode occur?）找到失效起因。
    • 构建 FM 与 FE 的关联：通过解答“失效模式会导致什么后果？”（What happens when the failure mode occurs?）找到失效影响。
2. 原书电机装配线（OP30 烧结轴承压入）失效结构树与表头解析
原书图 3.4-2 与图 3.4-3 给出了经典三层映射与表格编号规范：
  • 级别 1：过程项 / FE（表头 1）——对上一较高级别要素和/或最终用户的影响：
    • 您的工厂（本厂后道工序）：间隙太小无法安装轴，存在潜在碰伤/损害。
    • 发运至工厂（OEM/下一级客户）：将电机安装至车门上需要额外插入力，存在潜在损害。
    • 最终用户（车主/消费者）：舒适模式关闭时间过长。
    • 注：电子表格用户需注意，潜在失效模式可导致多个分类失效影响，分类记录可避免相同的失效模式与起因过多重复。
  • 级别 2：过程步骤 / FM（表头 2）——关注要素的失效模式：与产品特性直接关联。原书案例为：不能实现烧结轴承在电机壳内的轴向定位（间隙要求最大 < 0.3 mm 未达成）。
  • 级别 3：过程工作要素 / FC（表头 3）——4M 相关的失效起因：与过程特性关联。原书机器（Press Machine）案例为：设备在达到最终位置（止点）前停止运行。
  • 3.4.8 PFMEA 与 DFMEA 的关系纽带：PFMEA 关注的是过程无法实现设计特征（产品特性）。当过程失效导致不符合产品特性时，DFMEA 与 PFMEA 中的失效影响才是一致的。若属于过程特有失效或 DFMEA 未识别的影响，必须在 PFMEA 中重新定义评估，严禁纯主观假设。
3. 传音研发/制造实战场景（手机屏幕模组压合工序）
以传音中高端机型 AMOLED 屏幕与中框点胶贴合（OP40 屏幕保压压合工位）构建失效网：
  • 表头 2 - 关注要素失效模式（FM，针对过程步骤 OP40）：屏幕模组压合后平整度超差（面段差 > 0.15mm）或保压压力不足导致局部翘起（未满足产品特性）。（提问：为什么翘起？/ 会导致什么后果？）
  • 表头 3 - 工作要素失效起因（FC，针对 4M 机器与夹具）：保压机气缸下压位移传感器松动，导致压头未到达设定下死点即提前返程（机器）；治具限位槽存在残胶异物导致定位高度偏差（环境/工具）。
  • 表头 1 - 失效影响（FE，三层展开）：
    • 本厂下道（您的工厂）：中框保压后在整机超声气密性测试工位泄漏检测不通过（Yield loss / 返修拆屏导致盖板碎裂）。
    • 海外客户/区域仓库（发运）：长途海运受温湿度变化后整机发生屏幕脱胶起翘。
    • 终端消费者（最终用户）：手机在日常使用中整机 IP68 防尘防水失效，进水烧板；或者屏幕边缘漏光、触控漂移。
4. 常见误区与避坑指南
  • 误区 1：混淆因果关联，逻辑倒置。将 FE 写成 FC（例如把“整机气密测试漏气”当作压机下压不到位的起因）。纠偏：牢记“问为什么得起因，问后果得影响”，自下而上遵循物理传递链条。
  • 误区 2：在 PFMEA 中生搬硬套 DFMEA 的影响。部分工程师认为 PFMEA 的 FE 必须与 DFMEA 完全一字不差。纠偏：原书 3.4.8 明确指出，只有在“过程未实现产品设计特征”时两者最终用户影响才一致；所有因制造制造过程额外引入的风险（如碰伤、本厂组装报废、工厂装配额外插入力）必须在 PFMEA 中重新识别。
  • 误区 3：FE 仅写“本厂报废”，忽视下游与最终用户。只记录本工位不良，忽略了当不良流出后对客户工厂组装（发运工厂）及终端消费者（最终用户）的多层级影响。
